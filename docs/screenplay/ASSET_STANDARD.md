# 资产需求标准

资产解决的是**同一个对象在哪些画面上要长得一样**。图怎么画见[描述型素描](SKETCH_STYLE.md)。

## 分镜稿有两部分

| 部分 | 谁产出 | 是什么 | 有没有资产 |
|---|---|---|---|
| **文字版分镜稿** | 协作者直接写 | 分场、镜头顺序、每镜画面与动作、对白、时长 | 没有资产，只有文字稿 |
| **图格版分镜稿** | 生图模型按格生成 | 类似多格漫画：一格一个决定性时刻，与镜头、时间点对应 | 每格一张图 |
| **动态分镜** | 由上面两部分排时间 | 按镜内时间播放 | **复用图格里的图**作静帧/关键帧，不复制文件 |

图格的图不是一次性产物：同一张图在动态分镜里作为关键帧复用；要定稿时，把挑中的图转成项目风格关键帧，而不是重新画一张。

## 可复用资产：对象 × 形态

一个对象首次出场时建一张素描资产，此后所有镜头复用这一张。

| 类别 | 一张卡必须交代什么 | 什么时候另建一张（变体） |
|---|---|---|
| **角色** `appearance` | 可识别外形：脸型、身形、发型、服装、随身标志物 | 改造、受伤、年龄变化、伪装，以及有叙事意义的换装。标题写形态名（`李强·紫炎心改造后`），**不带镜头号** |
| **场景** `location` | 空间布局、尺度关系、主要陈设、材质与光线基调 | 同一地点不同时段（昼／夜／毁坏／改造后）。视角差异用参考图补，不建新卡 |
| **物品** `item` | 外形、材质、尺寸、磨损状态 | 碎裂、改造、进化、易手后的状态变化 |
| **材质** `material` | 质感、笔触参考 | 不绑节点，全局复用，不进镜头元素 |

**复用键是 `node_id`，不是标题。** 资产卡创建时写入对应提取节点；标题只是给人看的，改名不影响复用。变体之间靠形态名与生效范围（`valid_from` / `valid_to`）区分。

## 镜头级资产：跟着镜头走

| 资产 | 归属 | 说明 |
|---|---|---|
| 图格 | 镜头 + 时间点 | 一格一个决定性时刻；采用候选图后成为该镜的图稿 |
| 镜内关键帧 | 镜头内 `offset_ms` | 同一镜的不同时刻各自生成 |

**不建资产的东西**：文字分镜稿；特效与光影状态（紫光、白光瞬移这类写进画面描述与素描提示词，它不是对象）。

## 绑定规则

- 镜头元素只指向某个对象的**具体变体**；
- 一镜可绑多个对象，同一对象在一镜内只绑一个变体；
- 绑定依据是资产编号，不是标题字符串；
- 资产仍被镜头引用时不能删除，先解绑。

## 助手怎么管资产

模型随时可以：**检索 → 查看 → 绑定 → 修改 → 删除 → 缺了再生成**。

1. 检索：按关键词、类别、节点、有无图片、是否已被使用过滤；
2. 查看：卡片字段、图片、参考图，以及**被哪些场次/镜头的哪个元素引用**；
3. 绑定：把已有资产绑到某镜的某个元素，或解绑；
4. 修改：改标题、节点、形态名、生效范围、说明，单独增删图片与参考图；
5. 删除：被引用时先列位置并拒删，明确要求时才连绑定一起解除；
6. 生成：确实没有可用资产时，用图像服务按描述型素描生成，写回资产卡。

判断顺序固定：**先搜，再绑，最后才生成**。同名不代表同一对象，能对上 `node_id` 才算。
